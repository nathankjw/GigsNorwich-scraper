# Privacy Policy

**Norwich Gig List** (the "App")
Last updated: 1 November 2026

## What the App is

Norwich Gig List is a small personal automation that collects publicly listed gig information for Norwich venues and publishes it to the website [norwichgigs.com](https://www.norwichgigs.com). It runs automatically on a schedule using GitHub Actions.

## Who uses it

The App is used only by its owner. It is not offered to the public, and members of the public are never asked to sign in with Google or to give any information to the App.

## What Google data the App accesses

The App uses Google's OAuth with the Blogger API (scope: `https://www.googleapis.com/auth/blogger`) to do one thing: update a single page on the owner's own Blogger blog with the latest gig listings.

The App does not read, collect, or use any other Google account data, such as email, contacts, files, or calendar.

## What data the App collects

- **No personal data from visitors.** The App does not collect, store, or process any personal information about visitors to norwichgigs.com.
- **Gig information only.** The content the App handles is public event information (venue names, dates, artists, ticket links) gathered from publicly available sources.
- **Credentials.** The owner's OAuth credentials are stored as encrypted secrets in a private GitHub repository settings area and are used only to publish the page.

## Sharing and selling data

The App does not sell, share, rent, or transfer any user data to third parties. It does not use data for advertising.

## Data retention and deletion

The App keeps no user data. OAuth access can be revoked at any time at [myaccount.google.com/permissions](https://myaccount.google.com/permissions), after which the App can no longer access the blog.

## Google API Services User Data Policy

The App's use of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

## Changes to this policy

If this policy changes, the updated version will be posted here with a new "Last updated" date.
